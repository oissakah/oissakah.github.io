Flagship project

Emergent electron transport in self-assembled nanonecklace networks

A computational framework that connects microscopic network activation and topology to the macroscopic non-Ohmic current measured across a self-assembled nanoparticle network.

Read preprintView code
Scientific question

Where does the nonlinear I–V response come from?

A terminal current–voltage curve shows the electrical response of the whole material, but it does not show how that response emerges internally. This project asks what happens inside the network as the applied voltage increases: which nodes become active, when a source-to-drain path first forms, how the conducting structure changes, and how current redistributes through individual edges.

Key perspective: treat the nanonecklace as an evolving electrical graph whose internal state can be solved directly, rather than as a black-box nonlinear element.
Model

Physics-based computational framework

01 · Activate

Voltage-dependent graph

Nodes become electrically active according to their activation thresholds. The active subgraph changes with applied voltage.

02 · Solve

Kirchhoff electrical state

The conducting graph is solved under source/drain boundary conditions to obtain nodal potentials and edge currents.

03 · Diagnose

Internal transport dynamics

Connectivity, spanning structure, activation, edge-current distributions, and current redistribution are tracked alongside the macroscopic current.

Mechanism

Non-Ohmic behavior as a network-level phenomenon

The simulations support a three-stage physical picture of the electrical response.

Phase 1

Blockade

The active graph does not yet contain a source-to-drain spanning structure, so sustained macroscopic transport is absent.

Phase 2

Emergent non-Ohmic transport

Additional activation changes connectivity and opens new current-carrying routes. Network growth and redistribution drive a strongly nonlinear rise in current.

Phase 3

Quasi-Ohmic regime

As activation approaches saturation, topology changes less strongly and the electrical response becomes closer to a fixed conducting network.

Why this matters

Seeing the internal state changes what can be learned

Beyond terminal prediction

Two different internal networks can produce similar terminal currents. By resolving edge currents and active topology, the model can distinguish mechanisms that an I–V curve alone cannot reveal.

Controlled computational experiments

Network size, activation statistics, topology, and void fraction can be varied independently, allowing causal structure–property relationships to be separated from experimentally entangled variables.

Machine learning extension

Graph neural networks as transport surrogates

The physics model also creates a rich supervised-learning dataset: each graph has structural information, an applied voltage, a macroscopic response, and an internal electrical state. I use graph neural networks to learn fast surrogates for this system and test whether learned representations generalize to network conditions outside the training distribution.
