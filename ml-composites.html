Published project

Machine learning for sustainable composite design

A data-driven framework for predicting the full tensile stress–strain response of palm-kernel-shell/calcium-carbonate reinforced HDPE composites, built on experimentally characterized materials.

2026 ML paper2025 experimental paper
Scientific question

Can we predict composite deformation without repeating every mechanical test?

Hybrid PKS/CaCO₃/HDPE composites combine a polymer matrix with agricultural-waste and mineral fillers. Their mechanical response depends on composition, particle size, deformation state, and filler–matrix interactions, making empirical optimization expensive.

Core idea: combine experimentally grounded materials data with physics-informed features and interpretable machine learning to predict the full tensile response and expose structure–property relationships.
8,284stress–strain data points used in the published ML study

Model A

Full-feature prediction

The Extra Trees model achieved R² = 0.9998, MAE = 0.0385 N/mm², and RMSE = 0.0621 N/mm² on the held-out test set.

Model B

Prediction without prior tensile modulus

A modulus-free model retained R² = 0.9982 and 0.46% MAPE, showing that accurate stress–strain prediction can be achieved without prior modulus characterization.

Feature engineering

Encoding materials physics into the learning problem

The model was not limited to raw composition labels. Features were designed to represent aspects of the underlying composite structure and deformation.

Composition & morphology

PKS/CaCO₃ content, particle-size information, volume fractions, and related descriptors describe how the hybrid filler population changes.

Interparticle & interface descriptors

Physics-informed features encode interparticle spacing, surface-area interaction, and filler–matrix relationships that influence load transfer.

Deformation-state variables

Strain and strain-extension coupling allow the model to predict the evolving stress response rather than only one scalar property.

Interpretability

SHAP analysis identifies non-linear dependence on tensile modulus, strain, PKS content, and interparticle spacing.
