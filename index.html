Featured research

Emergent electron transport in nanonecklace networks

A flagship project combining graph representations, Kirchhoff circuit physics, percolation, network science, and graph neural networks to connect microscopic network state to macroscopic electrical response.

Physics-based network model · GNN surrogate

From network activation to the measured I–V curve

Instead of treating the material as a black box, the framework resolves the active conducting graph, nodal potentials, edge currents, connectivity, and the evolving pathways that produce the two-terminal current.

Core idea: the non-Ohmic response emerges collectively as voltage activates more of the network and creates a spanning conducting structure.

Nanomaterial electron transport

How does a changing microscopic network create emergent macroscopic conduction?

Graph-based Kirchhoff modeling, voltage-driven percolation, internal current redistribution, and learned surrogates for fast prediction.

Which surface environments control adsorption and reactivity?
